# Product case studies

**Live at ashishsrivastava1406.github.io** — replace with your own domain once you have one.

Case studies on consumer growth, monetisation and platform product work: the
constraint, the decision, the alternatives considered, and what the measurement
showed.

## Files

Flat. No folders, no build step, no framework. Every file sits at the root.

| File | What it is |
| --- | --- |
| `index.html` | Homepage: scope, case study list, numbers, how I work, earlier work, about |
| `tournament-lobby-revamp.html` | Case study |
| `tournament-recommendations.html` | Case study |
| `tournament-ingress.html` | Case study |
| `bot-perception.html` | Case study |
| `reactivation-on-live-signals.html` | Case study |
| `style.css` | All styling for every page |
| `*.jpg` | Redacted screenshots |

Diagrams are inline SVG inside the case study pages, so they scale, stay
readable at any size, and need no image files.

## Navigation

- Sticky primary nav on every page, with the current section marked
- Breadcrumb on each case study: home, case studies, current page
- On this page: jump links to each section of a case study
- Previous and next case study at the foot of each one, plus a link back to the full list
- Skip link to main content for keyboard users

## Editing

Open a file in GitHub, click the pencil, edit, commit. Prose sits inside `<p>`
tags — change the words, leave the tags.

To change the look of every page at once, edit `style.css`. Colours are CSS
variables at the top.

## Adding a case study

1. Copy an existing case study file and rename it.
2. Replace the breadcrumb title, eyebrow, headline, standfirst and body.
3. Update the on-this-page list to match your section headings.
4. Add a row for it in the case studies section of `index.html`.
5. Fix the previous and next links on the case studies either side of it.

## Custom domain

Add a file named `CNAME` at the root containing only your domain, then set the
domain under Settings, Pages. Update the live URL at the top of this file.

## Disclosure

Relative movement and rates only. No absolute revenue, customer counts or
per-brand retention figures from a current or former employer. Screenshots have
player handles, balances and promotional codes redacted. Where a conclusion is
an interpretation rather than something an analysis stated, the case study says
so.

Resumes are not published here. They carry absolute figures and go to
recruiters directly.
